PANDUAN LOKAL RUN-LOCAL
=======================

Dokumen ini hanya untuk development lokal. `run-local-php.sh` boleh memuat `.env`
lokal yang tidak dilacak Git dan menjalankan `php -S` pada `127.0.0.1:8000`.
Sebelum menjalankannya, operator lokal harus menyiapkan sendiri seluruh direktori
runtime yang diperlukan; launcher tidak membuat direktori runtime atau upload.

Jangan gunakan dokumen ini, `run-local-php.sh`, Apache, atau `.env` untuk
production. Satu-satunya runbook production adalah
`docs/PANDUAN_DEPLOY_PRODUCTION_ALMALINUX.md` (serta salinan `.txt`), yang memakai
Nginx, PHP-FPM, dan konfigurasi native `/etc/ami/production.php` di luar webroot.
