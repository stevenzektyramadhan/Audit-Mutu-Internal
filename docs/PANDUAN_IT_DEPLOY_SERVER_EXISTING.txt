CHECKLIST TUGAS TIM IT - DEPLOYMENT AUDIT MUTU INTERNAL (AMI)
Target Server: AlmaLinux / RHEL / CentOS

================================================================================
DAFTAR TUGAS YANG HARUS DILAKUKAN TIM IT (ACTION ITEMS)
================================================================================

1. EKSTRAK APLIKASI
   - Letakkan isi folder paket di web root (misal: /var/www/html/ami).
   - Pastikan file index.php berada langsung di root folder tersebut.

2. SET ATURAN PERMISSION & SELINUX
   - Atur kepemilikan folder web root ke user/group web server (misal: nginx / apache).
   - Pastikan folder berikut memiliki izin tulis (writable):
     * uploads/
     * application/cache/
     * application/logs/
   - Jika SELinux berstatus Enforcing, beri konteks 'httpd_sys_rw_content_t' pada ketiga folder di atas.

3. SETUP DATABASE (PILIH SALAH SATU):
   - Buat database MySQL/MariaDB baru (contoh nama: 'ami', charset utf8mb4).
   - Buat user database dengan hak akses penuh ke database tersebut.
   - Eksekusi database:
     * OPSI A (Rekomendasi - Cepat & Praktis):
       Impor file 'database_init.sql' ke database 'ami'.
       File ini sudah otomatis membuat seluruh tabel terbaru sekaligus akun Super Admin awal.
       Saat pertama kali login, sistem akan otomatis mewajibkan pergantian password.
     * OPSI B (Custom Akun Admin via Terminal):
       Impor file 'database_schema.sql' (hanya skema tabel kosong).
       Lalu jalankan perintah terminal:
       php scripts/bootstrap_super_admin.php
       (Masukkan nama, email, dan password admin yang diinginkan).

4. SESUAIKAN 3 FILE KONFIGURASI
   Buka folder: application/config/production/
   - config.php   : Isi 'base_url' dengan domain/subdomain kampus (wajib HTTPS), dan isi 'encryption_key' minimal 32 karakter acak.
   - database.php : Isi username, password, dan nama database yang telah dibuat.
   - ami.php      : Pengaturan path storage (biarkan default menggunakan folder uploads/ lokal).

5. BUAT VIRTUAL HOST / SERVER BLOCK NGINX
   - Buat file konfigurasi vhost baru untuk domain aplikasi AMI.
   - Arahkan 'root' ke /var/www/html/ami dan 'index' ke index.php.
   - Arahkan eksekusi PHP ke socket atau port PHP-FPM server.
   - Blokir akses langsung via web ke folder: application, system, vendor, serta subfolder uploads privat (audit_evidence, ppepp_documents, dll.).
   - Blokir eksekusi file script .php di dalam seluruh folder uploads.
   - Reload Nginx setelah konfigurasi valid (nginx -t).

6. VERIFIKASI AKHIR
   - Jalankan tool diagnosa dari terminal:
     php scripts/ami_doctor.php
   - Buka URL domain di browser, pastikan halaman login terbuka normal dan coba login dengan akun Super Admin.
